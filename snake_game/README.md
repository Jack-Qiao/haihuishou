# 贪吃蛇游戏 (Snake Game)

一个使用Python和pygame实现的经典贪吃蛇游戏。

## 功能特性

- 🐍 经典的贪吃蛇游戏玩法
- 📊 实时计分系统
- 🎮 流畅的游戏控制
- ⏸️ 暂停/继续功能
- 🔄 游戏结束后重新开始
- 🎨 美观的游戏界面
- ⭐ 升级系统与技能树
- 🎯 被动技能和主动技能
- 🌟 精美的视觉效果和粒子系统
- 🍎 大食物系统（每3个食物出现1个大食物）
- 🚧 动态障碍物系统

## 游戏规则

1. 控制蛇移动收集食物
2. 普通食物：10分，蛇身增长1格
3. 大食物（紫色）：50分，蛇身增长5格（每3个食物出现1个）
4. 临时食物（黄色）：5分，由主动技能生成
5. 撞到障碍物或自己的身体游戏结束
6. 收集经验值升级，获得技能
7. 尽可能获得更高分数和更多技能！

## 操作方法

- **方向键**: 控制蛇的移动方向
  - ↑ 向上移动
  - ↓ 向下移动
  - ← 向左移动
  - → 向右移动
- **空格键**: 暂停/继续游戏
- **R键**: 游戏结束后重新开始
- **ESC键**: 退出游戏
- **数字键1-3**: 使用主动技能（需要先获得技能）

## 安装和运行

### 环境要求
- Python 3.x
- pygame 2.0.0+

### 安装依赖
```bash
pip3 install pygame
```

### 运行游戏
```bash
python3 snake_game.py
```

## 技能系统

### 升级机制
- 每吃到一个普通食物获得20经验值
- 每吃到一个大食物获得100经验值
- 每吃到一个临时食物获得10经验值
- 升级所需经验值随等级递增
- 每次升级随机获得一个被动技能或主动技能

### 被动技能（自动生效）

| 技能名称 | 效果描述 | 获取概率 |
|---------|---------|---------|
| **Speed Boost** | 移动速度提升50% | 随机 |
| **Double Points** | 所有得分翻倍 | 随机 |
| **Magnet** | 自动吸引附近食物 | 随机 |
| **Thick Skin** | 30%概率免疫伤害 | 随机 |
| **Regeneration** | 每5秒自动增长1格 | 随机 |
| **Lucky Charm** | 20%概率三倍得分 | 随机 |
| **Ghost Mode** | 20%概率穿透障碍物 | 随机 |
| **Iron Stomach** | 10%概率额外增长 | 随机 |

**被动技能特点：**
- 最多可拥有5个被动技能
- 技能效果永久生效
- 无需手动激活

### 主动技能（需要手动使用）

| 技能名称 | 效果描述 | 冷却时间 | 快捷键 |
|---------|---------|---------|--------|
| **Shield** | 3秒无敌状态 | 10秒 | 1 |
| **Teleport** | 随机传送到安全位置 | 5秒 | 2 |
| **Time Slow** | 游戏速度减慢 | 15秒 | 3 |
| **Food Rain** | 生成3-5个临时食物 | 20秒 | 1-3 |
| **Clear Obstacles** | 清除所有障碍物 | 30秒 | 1-3 |
| **Super Speed** | 超高速移动4秒 | 8秒 | 1-3 |
| **Invincibility** | 完全无敌10秒 | 25秒 | 1-3 |

**主动技能特点：**
- 最多可拥有3个主动技能
- 需要按数字键1-3激活
- 有冷却时间限制
- 技能效果强大但有限制

### 技能获取策略
1. **优先选择被动技能**：提供持续增益
2. **合理搭配主动技能**：根据游戏情况选择
3. **注意技能冷却**：在关键时刻使用主动技能
4. **升级优先级**：早期获得速度提升和双倍得分

## 游戏界面

游戏包含以下界面元素：
- **左侧技能面板**：显示所有技能和说明
- **中央游戏区域**：星空背景的贪吃蛇游戏
- **右侧信息面板**：分数、等级、经验值等
- **霓虹绿色蛇身**：带发光效果的蛇
- **彩色食物系统**：普通食物（橙色）、大食物（紫色）、临时食物（黄色）
- **红色障碍物**：随机生成的危险区域
- **粒子效果**：技能激活、升级、死亡等特效

## 技术实现

- **游戏引擎**: pygame
- **编程语言**: Python 3
- **架构模式**: 面向对象设计
- **主要类**:
  - `SnakeGame`: 主游戏类
  - `Colors`: 颜色常量（包含霓虹色彩）
  - `Direction`: 方向枚举
  - `GameConfig`: 游戏配置
  - `Particle`: 粒子效果系统
- **核心系统**:
  - 技能管理系统（被动/主动技能）
  - 升级和经验值系统
  - 粒子效果系统
  - 动态障碍物生成
  - 大食物系统
  - 星空背景效果

## 游戏配置

可以在 `GameConfig` 类中调整以下参数：
- 窗口大小 (1300x600，包含技能面板和UI面板)
- 技能面板宽度 (250px)
- UI面板宽度 (250px)
- 游戏区域大小 (800x600)
- 网格大小 (20px)
- 游戏速度 (10 FPS，可随等级提升)
