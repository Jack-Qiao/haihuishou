# Snake Game - 模块化版本

## 项目结构

```
snake_game/
├── main.py              # 主启动文件
├── game.py              # 主游戏逻辑
├── constants.py         # 常量定义（颜色、配置等）
├── particle.py          # 粒子系统
├── skill_system.py      # 技能系统
├── renderer.py          # 渲染器
├── requirements.txt     # 依赖包
├── README.md           # 原始文档
└── README_MODULAR.md   # 模块化版本文档
```

## 模块说明

### 1. constants.py
- **Colors**: 颜色定义类，包含所有游戏中使用的颜色
- **Direction**: 方向枚举类
- **GameConfig**: 游戏配置类，包含窗口大小、网格大小等

### 2. particle.py
- **Particle**: 粒子类，用于创建各种视觉效果
- 支持位置、速度、生命周期、大小等属性
- 自动更新和绘制功能

### 3. skill_system.py
- **SkillSystem**: 技能系统类
- 管理被动技能和主动技能
- 处理技能获取、冷却时间、效果应用
- 提供技能名称和描述映射

### 4. renderer.py
- **Renderer**: 渲染器类，负责所有绘制工作
- 背景绘制（渐变、星空效果）
- 游戏对象绘制（蛇、食物、障碍物）
- UI绘制（技能面板、信息面板）
- 粒子效果绘制

### 5. game.py
- **SnakeGame**: 主游戏类
- 游戏状态管理
- 事件处理
- 游戏逻辑更新
- 协调各个系统

### 6. main.py
- 程序入口点
- 启动游戏

## 优势

### 1. 代码组织
- **单一职责**: 每个模块负责特定功能
- **高内聚**: 相关功能集中在同一模块
- **低耦合**: 模块间依赖关系清晰

### 2. 可维护性
- **易于修改**: 修改某个功能只需关注对应模块
- **易于扩展**: 添加新功能可以创建新模块
- **易于测试**: 可以单独测试每个模块

### 3. 可读性
- **清晰结构**: 代码结构一目了然
- **职责明确**: 每个文件的作用明确
- **便于理解**: 新开发者容易理解项目结构

### 4. 复用性
- **模块复用**: 其他项目可以复用特定模块
- **组件化**: 技能系统、粒子系统等可以独立使用

## 开发规范

### 1. 命名规范
- 文件名使用小写字母和下划线
- 类名使用大驼峰命名法
- 函数和变量使用小写字母和下划线

### 2. 文档规范
- 每个模块都有文档字符串
- 重要函数都有注释说明
- 复杂逻辑有详细注释

### 3. 导入规范
- 标准库优先
- 第三方库其次
- 本地模块最后
- 按字母顺序排列

## 性能优化

### 1. 渲染优化
- 使用精灵图（sprite sheets）
- 实现对象池
- 减少不必要的重绘

### 2. 内存优化
- 及时清理粒子效果
- 重用对象而不是创建新对象
- 使用弱引用避免循环引用

### 3. 算法优化
- 优化碰撞检测算法
- 使用空间分区技术
- 减少不必要的计算
