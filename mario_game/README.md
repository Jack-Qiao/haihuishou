# Super Mario Game 🍄

一个使用Python和pygame实现的经典超级玛丽平台跳跃游戏。

## 🎮 游戏特性

- **经典平台跳跃玩法** - 跳跃、移动、收集道具
- **物理引擎** - 重力系统和精确的碰撞检测
- **敌人系统** - 蘑菇怪等敌人，可以跳跃消灭
- **道具收集** - 金币收集系统
- **生命系统** - 3条生命，受伤后有无敌时间
- **分数系统** - 消灭敌人和收集金币获得分数
- **摄像机跟随** - 平滑的摄像机跟随效果
- **关卡设计** - 多个平台和挑战

## 🕹️ 操作方法

- **方向键 / WASD**: 移动玛丽
  - ← / A: 向左移动
  - → / D: 向右移动
- **空格键**: 跳跃
- **ESC键**: 退出游戏
- **R键**: 游戏结束后重新开始

## 🎯 游戏目标

1. **收集所有金币** - 收集关卡中的所有金币获得胜利
2. **消灭敌人** - 跳到敌人头上消灭它们获得分数
3. **避免受伤** - 避免被敌人从侧面撞击
4. **生存到最后** - 保持生命值不为零

## 🏆 计分系统

- **消灭敌人**: +100 分
- **收集金币**: +200 分
- **胜利奖励**: 收集所有金币获得胜利

## 🎨 游戏元素

### 玛丽角色
- 红色矩形表示玛丽
- 受伤时会闪烁橙色（无敌状态）
- 有白色眼睛和红色帽子

### 敌人
- 棕色蘑菇怪，会左右移动
- 可以通过跳跃消灭
- 从侧面接触会受伤

### 道具
- 黄色旋转金币
- 收集后消失并获得分数

### 平台
- 绿色浮空平台
- 棕色地面平台
- 支持完整的碰撞检测

## 🛠️ 技术实现

- **游戏引擎**: pygame
- **编程语言**: Python 3
- **架构模式**: 面向对象设计
- **主要类**:
  - `MarioGame`: 主游戏类
  - `Player`: 玩家角色类
  - `Enemy`: 敌人类
  - `Coin`: 金币类
  - `GameState`: 游戏状态枚举

## 📋 游戏配置

可以在 `GameConfig` 类中调整以下参数：
- 窗口大小: 1000x600
- 帧率: 60 FPS
- 重力强度: 0.8
- 跳跃力度: -15
- 移动速度: 5

## 🚀 安装和运行

### 环境要求
- Python 3.x
- pygame 2.0.0+

### 运行游戏
```bash
python3 mario_game.py
```
