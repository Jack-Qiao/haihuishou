# codingAi

本地练习与工具集合，各子目录为独立项目，互不依赖。

## 项目一览

| 目录 | 说明 |
|------|------|
| [haihuishou/](haihuishou/) | 嗨回收抢单工具（Web UI + CLI + 打包） |
| [zhuabao/](zhuabao/) | 微信小程序代理抓包与数据导出 |
| [snake_game/](snake_game/) | 贪吃蛇（pygame） |
| [mario_game/](mario_game/) | 超级玛丽风格平台跳跃（pygame） |
| [biddingHero/](biddingHero/) | 预留项目目录 |

## 快速开始

每个项目都有自己的 `README.md` 与 `requirements.txt`，进入对应目录安装依赖后即可运行。

```bash
# 嗨回收抢单 UI
cd haihuishou && ./run

# 抓包
cd zhuabao && python3 run_capture.py

# 贪吃蛇
cd snake_game && python3 run.py

# 超级玛丽
cd mario_game && python3 mario_game.py
```
